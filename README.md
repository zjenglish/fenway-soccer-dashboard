# Fenway High Soccer Program Dashboard

Live roster, schedule, and team information for the Fenway High multi-school soccer program (2026-2027 season).

**🌐 Access online:** [zjenglish.github.io/fenway-soccer-dashboard](https://zjenglish.github.io/fenway-soccer-dashboard/)

## Features

- ⚽ Interactive schedule with 18 games (Sept-Oct 2026)
- 🏀 Multi-school roster (Fenway, Snowden International, Josiah Quincy Upper, CASH Charter)
- 📋 Real-time paperwork status tracking
- 👥 Coaching staff: Zach English (Head Coach), Beni Martinez (Assistant Coach), Marcos Baez (Athletic Director)
- 🎮 Animated soccer balls, custom cursor, rolling ball on page load
- 📱 Responsive mobile-friendly design
- 🔗 Quick links to BPS Athletics, MIAA, MA Department of Education

## How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/zjenglish/fenway-soccer-dashboard.git
   cd fenway-soccer-dashboard
   ```

2. Serve locally (requires Python):
   ```bash
   python3 -m http.server 8000
   ```

3. Open in browser: `http://localhost:8000`
